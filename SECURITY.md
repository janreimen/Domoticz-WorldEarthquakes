# Security Policy

## Supported Versions

We take the security of the World Earthquakes Domoticz plugin seriously. Security updates are provided for the latest stable release.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not open a public GitHub issue**. Instead, please report it privately:

* **Email:** [jan.reimen@pt.lu](mailto:jan.reimen@pt.lu)
* **GitHub Private Vulnerability Reporting:** You can also use GitHub's private reporting feature under the **Security** tab of the repository.

Please include as much detail as possible in your report, including:
* A description of the vulnerability and how it can be reproduced.
* Potential impact or risk associated with the issue.
* Any relevant logs, code snippets, or configuration details.

We will review all reports promptly and work with you to coordinate a responsible public disclosure if necessary.
